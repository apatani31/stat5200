# The Stablecoin Dollar Premium in Emerging Markets

STAT 5200 (Applied Econometrics I), Fall 2026. Author: Ahan Patani.

How large and persistent is the premium residents of emerging markets pay to buy
dollars through USDT stablecoin markets, how does it respond to devaluations and
FX controls, and does it carry the same information as Bitcoin-based premia?

## Reproduce everything

```bash
python R/01b_pull_refinitiv.py   # optional; needs LSEG Workspace open
```

```r
install.packages("renv")
renv::restore()          # installs the exact package versions in renv.lock
source("run_all.R")      # or, from a terminal: Rscript run_all.R
```

Then compile `paper/proposal.tex` (it reads `output/tables/desc_stats_proposal.tex`).

## Key variable

`usdt_premium = log(USDT price in local currency / official USD rate)`.
Weekend official rates are carried forward from the last quote.
`exp_dep_1m = log(F_1M / S)` is forward-implied expected depreciation (Refinitiv only).

## Licensed data

Refinitiv data cannot be redistributed. The repository contains the pull script
and RIC list; anyone with Workspace access regenerates the file. Without it,
`02_clean.R` falls back to Yahoo spot rates and skips the forward-based variables.

## Coding standards

One script per stage, numbered in run order; all paths via `here()`; no
`setwd()`; raw data never modified; settings defined once in `00_config.R`;
package versions pinned with `renv`; outputs regenerated by `run_all.R`.
